# Abschlussarbeits-Matching

Abschlussarbeits-Matching ist eine Webanwendung, die Studierenden hilft, passende Betreuer:innen und Themen für ihre Abschlussarbeit zu finden. Die Plattform bietet Profilseiten mit Themen, Tags, Dateien und Links sowie ein Matching-System basierend auf Interessen und besuchten Kursen.

Backend und REST APIs wurden in Java mit Spring Boot umgesetzt, Deployment erfolgt über Docker.
Die Authentifizierung erfolgt über GitHub OAuth, drei Rollen sind vorgesehen: Admin, Betreuende und Studierende.
